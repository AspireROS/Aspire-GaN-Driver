# 🔌 HPM5E3YIVK1 接口定义要求

## 🎯 1. 文档目的

本文档定义 HPM5E3YIVK1 的外部接口、板内高速信号和 MCU 复用资源，供原理图、PCB、软件初始化和测试使用。

信号名称以 `Hardware/Doc/Pin Assignment/Pin Assignment.csv` 为当前基线。接口的额定电压、速率、终端和连接器针脚必须结合最新原理图及器件数据手册确认。

## 🗂️ 2. 接口总览

| 接口 | MCU/控制器资源 | 当前引脚分配 | 主要要求 |
| --- | --- | --- | --- |
| EtherCAT/PHY | `ESC0`、`ENET_PHY` | `PA16`-`PA31`、`PV00`-`PV15`、`PW00`-`PW21` 等 | 差分信号、参考时钟、复位、MDIO/MDC、状态指示和阻抗控制 |
| 以太网 MAC | `ETH0` | `PF02`-`PF14` | TX/RX 时钟、数据、使能和错误信号应成组布线 |
| CAN | `MCAN0` | `PD00` TXD、`PD01` RXD | 收发器、电平、终端电阻、保护和连接器定义 |
| UART | `UART0.A` | `PA00` TXD、`PA01` RXD、`PA02` RTS、`PA03` CTS | 默认电平、流控是否启用和调试连接器定义 |
| JTAG | `JTAG.A` | `PA04`-`PA08` | 调试器连接、复位、信号完整性和防误插 |
| SPI | `SPI1.B` | `PC09` CS、`PC10` SCLK、`PC12` MISO、`PC13` MOSI | 片选时序、模式、速率和外设电源域 |
| QEI | `QEI1.B` | `PB29` Z、`PB30` A、`PB31` B | A/B/Z 相定义、输入电平、滤波和屏蔽 |
| PWM | `PWM0.D.P[2:7]` | `PD02`-`PD07` | 默认关闭状态、互补关系、死区和故障关断 |
| ADC | `ADC0.A` | `PF16`、`PF18`-`PF27` | 输入范围、采样网络、滤波、保护和模拟地回流 |

## 🔧 3. 接口定义

### 🌐 3.1 EtherCAT/以太网

- `ESC0` 和 `ENET_PHY` 相关信号应按照 PHY/ESC 的数据手册及原理图定义。
- 差分信号应成对命名、成对布线，并保持连续参考平面。
- `MDIO`/`MDC`、PHY 复位、参考时钟和链路状态信号不得与高噪声开关节点共线。
- 连接器侧应配置适配的 ESD/浪涌保护，保护器件型号参考 `PRTR5V0U2X.pdf`。
- 端接、磁性器件、共模器件和连接器针脚需在原理图中明确标注。

### 🚌 3.2 CAN

- `MCAN0.D.TXD` 和 `MCAN0.D.RXD` 分别连接 CAN 收发器的 TXD/RXD。
- CANH/CANL 应使用差分走线，并根据总线拓扑配置终端电阻。
- 连接器应明确 CANH、CANL、GND 和屏蔽/机壳地的定义。
- 收发器和保护器件的电源、电平及待机控制必须与 MCU 电源域匹配。

### 🖥️ 3.3 UART

- `UART0.A.TXD`、`UART0.A.RXD` 为基本调试通信信号。
- `UART0.A.RTS`、`UART0.A.CTS` 仅在硬件和软件均启用流控时使用。
- 调试接口应明确电平标准、连接器方向、GND 和默认上拉/下拉状态。

### 🛠️ 3.4 JTAG

- `TDO`、`TDI`、`TCK`、`TMS` 和 `TRST` 应按调试器接口顺序连接。
- JTAG 走线应远离 PWM 功率开关节点，并预留调试测试点或标准连接器。
- 复位、供电参考和地必须与调试器连接器一起定义。

### ⚡ 3.5 SPI、QEI、PWM 和 ADC

- SPI 片选必须与具体从设备一一对应，未使用的片选不得悬空。
- QEI A/B/Z 必须在文档、原理图和软件中保持同一相位定义。
- PWM 输出在复位、启动、故障和通信丢失状态下必须有明确的安全电平。
- ADC 输入必须标注信号来源、量程、分压比例、滤波参数和保护方式。

## 📝 4. 信号命名与变更规则

- 原理图、PCB、引脚分配表、软件初始化和测试记录使用一致的逻辑信号名。
- 修改 MCU 复用功能时，必须检查同组资源冲突及备用功能占用。
- 新增外部接口时，应同步补充连接器定义、供电、保护、终端和验收项目。
- `undefined` 位置的专用 ESC/PHY 信号不得直接当作普通 GPIO 使用，需以 MCU 数据手册和原理图为准。

## ❓ 5. 待确认项目

- 各连接器的物理型号、针脚顺序和机械防呆。
- EtherCAT 端口数量、PHY 型号、参考时钟和差分阻抗。
- CAN 终端电阻配置、总线速率和隔离要求。
- UART/JTAG/SPI 的电平标准和最大通信速率。
- ADC 每路信号的实际量程、采样频率和校准方法。
