# 🧪 HPM5E3YIVK1 验收测试标准

## 🎯 1. 测试目的

本文档定义 HPM5E3YIVK1 硬件样板的设计评审、上电、接口、信号和安全验收项目。测试应在记录硬件版本、BOM 版本、测试设备和环境条件后执行。

除非项目评审另有规定，所有测试均应在限流、可控和满足安全防护的条件下进行。

## 🧰 2. 测试准备

- 待测板、对应版本原理图、PCB、BOM 和 `Pin Assignment.csv`。
- 可调直流电源、万用表、示波器、逻辑分析仪和 JTAG 调试器。
- CAN 分析工具、UART 工具、SPI/QEI/PWM/ADC 测试夹具或等效设备。
- EtherCAT 主站、网线和必要的 PHY/链路测试设备。
- 测试记录表，包含测试日期、操作者、板卡序列号、软件版本和结论。

## 🔍 4. 重点测试方法

### 🔋 4.1 电源测试

1. 上电前测量输入端和各电源轨对地电阻。
2. 使用限流电源逐步升压，观察输入电流和各电源轨启动顺序。
3. 在空载和代表性负载下测量稳态电压、纹波、启动过冲和关断行为。
4. 将实际测试值与原理图、数据手册和设计目标逐项对照。

### 🔌 4.2 接口测试

- 使用回环或外部设备验证 UART、CAN 和 SPI 的基本收发。
- 使用示波器或逻辑分析仪确认 PWM 频率、占空比、死区和故障关断。
- 使用已知电压或校准源验证 ADC 的比例、偏置和误差。
- 使用编码器模拟器或测试夹具验证 QEI A/B/Z 的方向和计数。
- 使用 EtherCAT 主站检查链路、从站识别、状态机和基本数据交换。

### ⚠️ 4.3 安全测试

- 低压、限流条件下先完成所有功能测试，再进行额定条件测试。
- 测试过程中不得直接接触裸露母线、功率器件和高速运动机构。
- 出现过流、过热、异常噪声、通信失控或器件温升异常时立即断电并记录。

## 🟢 5. 通过条件

- 所有 `AT-01` 至 `AT-17` 项目均有测试记录。
- 关键功能无未关闭的阻塞性缺陷。
- 所有未通过项目均有原因、风险评估、临时措施和后续责任人。
- 测试结果与实际硬件版本、软件版本和测试条件可追溯。
