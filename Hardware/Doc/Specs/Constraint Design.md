# 📐 HPM5E3YIVK1 设计约束

## 🏷️ 1. 约束优先级

设计约束按以下优先级执行：

1. 器件数据手册和绝对最大额定值。
2. 已评审的原理图、PCB 工程和接口定义。
3. 本文档及其他规格文档中的项目要求。
4. 经验性设计建议和可选优化方案。

发生冲突时，应暂停设计并通过评审记录确认，不得仅通过修改命名或布局规则规避约束。

## 🔋 2. 器件与电源约束

- 主控及其复位、时钟、启动和调试电路必须遵守 `HPM5E00.pdf` 的供电和时序要求。
- 电源转换器件应根据输入范围、输出电压、负载电流、开关频率、环路补偿和散热条件选型。
- 当前资料中的电源相关器件包括 `AP63205WU-7.pdf`、`LMR38020FDDAR.pdf`、`RT9013-33GB.pdf` 和 `TPS62A02DRLR.pdf`，每个器件的实际电源轨和装配状态必须以原理图/BOM 为准。
- 每个电源轨应配置足够的输入/输出电容、测试点和明确的地回流路径。
- 不得超过器件绝对最大额定值；额定工作条件应保留电压、电流和温升裕量。
- 外部接口保护器件 `PRTR5V0U2X.pdf` 应靠近接口放置，并根据被保护信号的速率和电容要求确认适用性。

## 🧭 3. PCB 布局布线约束

### 🌐 3.1 高速差分信号

- EtherCAT/以太网差分对必须保持连续参考平面，避免跨分割、长距离并行干扰和不必要的过孔。
- 差分阻抗应根据 PCB 叠层、线宽、线距和铜厚计算，并通过 PCB 厂商能力确认。
- 同一差分对应保持长度匹配，具体容差以 PHY/ESC 和 Layout 规则为准。
- PHY、变压器/磁性器件、连接器和 ESD 器件应按信号流向紧凑排列。

### ⚡ 3.2 电源与开关节点

- 开关电源输入回路、功率开关节点和输出回路应尽量短小、紧凑，降低寄生电感和 EMI。
- 高 di/dt 回路不得穿越 ADC、时钟、复位和高速差分信号的敏感区域。
- 功率地、数字地和模拟地的连接方式必须在原理图和 PCB 中明确，不得依靠大面积随机铺铜解决。
- 电源测试点应便于探头接地和示波器测量，避免引入额外长引线。

### 📈 3.3 模拟与采样信号

- ADC 输入网络应靠近 MCU 或信号源布置，并按采样带宽配置 RC 滤波。
- 模拟输入走线应远离 PWM、开关节点、时钟和高速差分线。
- 分压、采样电阻和保护器件的精度、功率和温漂应满足测量误差预算。

## 📡 4. 信号完整性与 EMC 约束

- CAN、UART、JTAG、SPI 等外部或调试信号应预留串联电阻或阻尼器件位置，以便调试边沿和振铃。
- 外部连接器应优先进行 ESD 电流回路设计，保护电流不得穿过 MCU 或模拟地敏感区域。
- 时钟和复位信号应减少分支，必要时配置串联阻尼和明确的上拉/下拉。
- PCB 上的天线效应较强的长线、悬空铜段和不必要测试焊盘应在评审中清理。

## 🏭 5. 结构、热和制造约束

- 高功耗器件应根据功耗、铜箔面积、导热过孔、散热器和环境温度评估结温。
- 器件高度、连接器方向、安装孔、板边禁布区和外壳干涉必须在 PCB 评审中确认。
- 关键器件应有清晰丝印、极性标记和可视化测试点。
- 封装、焊盘、钢网开口和器件间距应满足生产厂商的 DFM 要求。
- 版本号、板号和关键测试点应保留在 PCB 丝印或生产资料中。

## 🔄 6. 变更控制

- 器件替代必须重新检查电气参数、封装、引脚兼容性、热性能和供应状态。
- 引脚复用变更必须同步更新 `Pin Assignment.csv`、软件初始化和接口文档。
- PCB 叠层或阻抗目标变更必须重新检查所有高速差分网络。
- 每次版本发布前应完成 ERC、DRC、BOM、网络表、原理图和文档一致性检查。

## ❓ 7. 待确认参数

- PCB 叠层、差分阻抗目标和制造公差。
- 各电源轨的输出电压、最大电流、纹波和时序。
- 关键器件的功耗、工作温度和散热边界。
- 连接器、外壳、安装孔和板边机械尺寸。
- EMC、ESD、浪涌和绝缘测试等级。
